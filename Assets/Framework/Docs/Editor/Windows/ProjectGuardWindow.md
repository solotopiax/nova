# ProjectGuardWindow

窗口标题：`Nova · ProjectGuard`。菜单入口：`Nova/Open ProjectGuard`。

首行左侧显示中文名称“项目规范守卫”，Quick Validate 与 Build Validate 两个操作按钮靠右。窗口只展示 `EditorUtil.ProjectGuard` 报告；它不扫描额外范围、不持有规则、不修改 Scene、Build Settings、Collector 或资源，也不会自动触发或阻断 Unity Build。

规则与 profile 见 [EditorUtil.ProjectGuard](../EditorUtil/EditorUtil.ProjectGuard.md)。
