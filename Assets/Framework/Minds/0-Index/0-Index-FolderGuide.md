# Nova Minds 文件夹指南

## 顶层目录

| 路径 | 用途 | 默认是否查询 |
|---|---|---|
| [0-Index/](./) | 入口与导航 | 是 |
| [2-Areas/](../2-Areas/) | 当前有效知识 | 是 |
| [3-Resources/](../3-Resources/) | 外部资料与参考 | 按需 |
| [4-Archives/](../4-Archives/) | 旧决策、旧术语、旧记录 | 追溯时 |
| [Canvas/](../Canvas/) | 辅助图示 | 按需 |
| [Base/](../Base/) | Obsidian 知识视图 | 按需 |
| `.obsidian/` | 本机工作区与插件配置，不分发 | 否 |

以上知识目录整库公开，包含既有历史归档；默认查询范围不是发布筛选清单。纯文本阅读和 AI 查询无需安装 Obsidian，画布与视图可在支持对应格式的工具中打开。

## `2-Areas/` 内部分区

| 路径 | 用途 |
|---|---|
| `ADR/` | 架构决策 |
| `Patterns/` | 长期模式与反模式 |
| `Glossary/` | 术语定义 |
| `MOC/` | 模块图谱 |
| `Snapshots/` | 审计快照 |

## 写入原则

仅 Nova 开发仓真源按[工作指引](../AGENTS.md#默认写入策略)维护；消费项目只读随包知识。

- 当前实现说明写 `Docs`
- 长期结论写 `2-Areas`
- 高置信长期知识直接以正式编号写入 `2-Areas` 或 `3-Resources`
- 失效内容经确认后移入 `4-Archives`，不因公开而删除历史

## 默认不展开

- 本地工作区文件
- 工具过程文件
- 只对某一代协作栈成立的历史材料

这里限制日常阅读量，不缩减知识分发范围；本机配置与缓存除外。
