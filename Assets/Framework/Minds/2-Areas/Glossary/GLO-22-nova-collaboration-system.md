# GLO-22：Nova 协作体系

## 定义与范围

「Nova 协作体系」是对 Nova 规范约束、执行指导和知识联动整体的约定称谓。当前定义、范围与书写规则统一见 [Nova 协作体系](../../../Docs/Onboarding/AI_SKILLS_ACTIONS_MCP.md#nova-协作体系)。

## 约定原因

用户明确要求用一个稳定名称指代整体，避免每次维护、复盘和交付都重复枚举载体，也避免把各项更新误解为互不相干的工作。

统一名称不合并各自职责或改变优先级，不新增另一套目录、工具或自动化承诺。术语本身不授予执行权限，也不代表相关运行验收已经通过。

## 用法与易混淆项

- 整体说明使用“检查、完善、更新 Nova 协作体系”，不再逐项展开组成载体。
- 定位某个问题、接口或规则时保留准确文件名和路径，不用整体名称掩盖具体修改范围。
- Skill 的具体分类、Action 执行和 MCP 连接仍按 [[GLO-21-skill-action-mcp-boundary|GLO-21]] 区分，不能把整体称谓当成一个可调用工具。

## 来源、影响与验证边界

- 来源：用户于 2026-10-29 明确指定统一术语；当前表达约束已接入共同入口和治理任务。
- 影响：整体说明、维护请求、问题沉淀与交付措辞。精确技术定位不受影响。
- 本条确认术语与引用一致，不证明安装、构建、设备或外部服务运行成功。
