# MemoryProtection 文档

`com.solotopia.nova.framework.memory.protection` 是 Nova 的独立核心扩展包，提供可选 ACTk 整数内存防护、异常隔离、密钥轮换与埋点。

| 文档 | 内容 |
| --- | --- |
| [MemoryProtection.md](MemoryProtection.md) | 安装、配置迁移、程序集引用、读写与存档链、异常处理、生命周期、示例及裁剪 |
| [README.md](../../README.md) | 包依赖、商业插件购买与导入、Sample 入口 |

本包打点权威源为 `Nova/Tracks/Tracks.xlsx` 的 `打点表-MemoryProtection`；主框架 TrackRegistry 自动发现并汇总，事件、属性和上报目标保持原定义。
